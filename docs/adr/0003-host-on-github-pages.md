# Host on GitHub Pages instead of Zo or Cloudflare

The site is a pure static Vite build — no backend, no client-side routing — so hosting only needs a CDN that serves `dist/`. The previous setup pushed files one-by-one to a Zo site over the Zo MCP API (`scripts/deploy-zo.sh`), which required a personal token, a manual script run per deploy, and a second copy of the site outside the repo's control. GitHub Pages removes all of that: the repo is already public on GitHub, deploys run automatically on push to `main` via `.github/workflows/deploy.yml`, and there is no extra account, token, or CLI. To get the short URL `j-alicia-long.github.io/footprint/`, the repo was renamed from `ai-carbon-footprint` to `footprint`, and `vite.config.ts` sets `base: "/footprint/"` to match the Pages subpath (Pages serves project sites under the repo name; GitHub redirects the old repo URL). Accepted trade-offs: no PR preview deployments and a subpath rather than a root URL. Rejected: Cloudflare Workers Static Assets (root URL and PR previews, but a new account and CLI for a personal reference page that doesn't need them) and staying on Zo (manual, token-bound, and the deploy target could drift from the repo).
