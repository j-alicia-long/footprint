# Full-stack, location-based boundary for all Footprint numbers

Published per-query figures for the same class of model differ up to ~95× purely from measurement-boundary choice (Google's market-based 0.03 gCO₂e vs Mistral's full-LCA 1.14 gCO₂e per response). Every number on this page uses one fixed boundary — EcoLogits' full-stack model (GPU + server + PUE + amortized embodied hardware) with **location-based** grid intensity, per SCI/ISO 21031 — and boundaries are never mixed across Scenarios. This makes our numbers ~5–30× higher than provider-marketing figures (Altman's 0.34 Wh, Google's 0.03 g); that is deliberate honesty, not error. Rejected: GPU-only accounting (undercounts ~2.4×), market-based carbon (renewable credits hide physical emissions, and SCI forbids it).
