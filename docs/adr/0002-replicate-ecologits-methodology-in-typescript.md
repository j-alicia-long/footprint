# Replicate EcoLogits' methodology in TypeScript instead of calling it

EcoLogits is not a hosted API — it is a Python library that instruments _live_ LLM API calls and attaches impact estimates to real responses. This site is a static frontend with no backend and no live LLM requests: Scenarios are hypothetical presets, so there is nothing for EcoLogits to instrument, and running the library would require a Python server plus a network hop per estimate. Instead we replicate its formula chain (~40 lines in `src/footprint/compute-footprint.ts`), which keeps estimates instant, offline, and free, and — critically — lets every constant live in our cited Coefficient Set so Methodology Notes can surface each number rather than trusting a black box. Accepted trade-off: maintenance drift if EcoLogits revises its regression; mitigated by golden-value tests pinned to externally published anchors (Epoch AI, Mistral LCA), not to EcoLogits itself. Rejected: a thin Python proxy service (infrastructure cost for a static page), and client-side Pyodide (multi-MB payload for 40 lines of math).
